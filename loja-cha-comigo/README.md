# Chá Comigo · Loja de produtos naturais (protótipo)

Protótipo front-end (HTML, CSS e JavaScript puros). Sem backend, login ou pagamento.

## Como configurar
- Número do WhatsApp: variável `N` no início de `script.js` (formato DDI+DDD+número).
- Produtos: array `P` em `script.js`. As imagens ficam em `assets/`.

## Deploy no GitHub Pages
1. Crie um repositório e envie estes arquivos na raiz.
2. Em Settings > Pages, escolha Deploy from a branch, branch `main`, pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
